## Additional review gate added

Factory approvals now require a separate Ed25519 review attestation. Configure `REVELA_REVIEW_PRIVATE_KEY_PATH` (service secret manager) and `REVELA_REVIEW_PUBLIC_KEY_PATH` (service/local verification key) using the pair generated by `python -m core_foundry.keys`. The owner-side CLI refuses factory compilation if the attestation is missing or invalid, and offline Seed validates the signed approval as well as the plan license.

Registered `/v1/{tool_id}` tool invocations now dispatch only through a configured RVXP1 adapter and have no plaintext fallback. Python adapters can use `mesh.receiver.create_rvx_receiver_router`; the existing Go Core-Zero/One/Two receivers remain outstanding integration work.

The latest CI workflow also includes FastAPI license/meter/marketplace acceptance tests and Python RVXP1 receiver replay/content-type tests. Check the newest CI run on the branch before merging; an older passing run is not evidence that subsequent commits passed.
